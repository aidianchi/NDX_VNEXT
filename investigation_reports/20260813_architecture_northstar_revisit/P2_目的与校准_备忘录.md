## 核心结论（5 条，每条五件套）

### 结论 1｜"可测量地变好"是文档有、所有者原话没有的越权加项 → 裁决"改"，非"留"非"删"
- **判断对象**：CLAUDE.md 北极星"并让判断质量随时间可测量地变好"一句的处置。
- **支持证据**：任务 0 grep（CLAUDE.md:5、系统说明书.md:59 原文）；底稿第一节与第五节（2026-08-13，所有者原话与"未必正确"表态）。
- **反驳证据（留它的最强理由）**：所有者要"登峰造极、长期最大收益"，内含"系统应随时间变好"的真实诉求；且"可测量"对高频中间品（claim 方向 / 失效条件 / 风险清单）确能兑现，不必全删。
- **失效条件**：若所有者将来明确说"我就要判断被统计验证地变好"，并接受决策样本稀疏，则升级为"留（并补考核对象分层）"。
- **置信度**：高（0.8）。"原话没有"是文本铁证；"改而非删"是价值判断，略低。

### 结论 2｜校准闭环三环节现状 = 可评分✓ / 被事后评分✗ / 评分修正方法✗ → 裁决"存（改造）"，非"废"非"原样存"
- **判断对象**：三支柱之"校准闭环常开"的存废与考核对象。
- **支持证据（代码事实，可复跑）**：
  - 可评分✓：`src/agent_analysis/outcome_review.py` 的 `build_claim_outcome_scores`（T+20/60/120 对 QQQ）存在。
  - 被事后评分✗：`find output -name "claim_outcome_scores.json" | wc -l` → **0**；49 个 `outcome_review_report.json` 的 `claim_outcome_scores` 全为空，47/49 为 `not_applicable`（仅 2 个回测 run 产出市场级结果标签）。
  - 修正方法✗：`output/state_ledger/method_revision_ledger.jsonl` = **0 字节空文件**；`outcome_scoring_runner.py` 的 `NO_BACKFLOW_RULE` 明文禁止打分回流。
- **反驳证据（废它的最强理由）**：零真实打分 + 禁止回流 + 决策样本稀疏，闭环是"装饰性承诺"，废掉可减少虚假承诺。
- **失效条件**：若所有者定调"系统只为中性报告、不对决策负责"，闭环可大幅削减（但不废，因打分器对数据问题探测仍有价值）。
- **置信度**：高（0.85）。代码事实铁证；"存改造"是价值判断。

### 结论 3｜成功标准第一性：衡量"相对默认动作'不动'的决策增量"，而非"每篇判断对不对"
- **判断对象**：判断系统的"好"该用什么衡量。
- **支持证据**：所有者画像（任务书 2026-08-14 + 底稿第一节）：长期集中持有、极少出手、默认不动、要"长期最大收益"→ 决策点稀疏、基准=买入持有不动 → 价值=极少数偏离"不动"的决策事后是否跑赢基准。
- **反驳证据**：若系统同时服务"每周看报告、随时调整"的用户，"逐次判断正确率"仍有独立价值；且"决策增量"样本太小、难统计验证，可能沦为不可检验的口号。
- **失效条件**：所有者画像若变为频繁交易者，衡量标准应回移向逐次正确率。
- **置信度**：高（0.8）。

### 结论 4｜文章质量与决策价值：低端=必要地板（强正相关），高端=弱相关甚至背离；两者评分对象不在同一统计母体
- **判断对象**：文章质量（事实扎实/证据对称/冲突保留/可追溯/隔离可查）与决策价值的关系。
- **支持证据**：
  - 低端正相关（自证推导）：数字造假 / 证据偏科 / 冲突抹平 → 决策必错，质量是决策价值的必要地板。
  - 高端背离（自证推导 + 代码事实）：现有打分器考"claim 方向对不对"（`outcome_review.py`），不等于"决策赚没赚"；对"极少出手"的所有者，多数正确判断="不动"=零决策增量；且高质量中性报告有"和稀泥"倾向（系统说明书 2.4 已把"谨慎/骑墙当默认安全答案"列为与冒进同级的失真）。
- **反驳证据**：决策价值依赖判断质量做输入，长期看低质量系统不可能持续产出好决策；"背离"可能只是"测量错了对象"而非真背离。
- **失效条件**：若证明"claim 方向正确率"与"决策事后收益"在足够样本上显著正相关，则背离论点退化为"当前打分器未对齐决策"。
- **置信度**：中高（0.7）。"必要地板"是逻辑必然；"高端背离"缺直接实证样本（系统零真实决策记录）。

### 结论 5｜校准闭环改造方向 = 考核对象分层：高频中间品走统计闭环，低频决策走过程审计+如实记账，不承诺决策层"可测量变好"
- **判断对象**：改造后的校准闭环该考核什么。
- **支持证据（外部实证，均经 Crossref/PubMed 核实卷期页码）**：
  - Murphy 1973《A New Vector Partition of the Probability Score》，J. Applied Meteorology 12(4):595-600（1973-06）——Brier 分数分解 = 可靠性 − 分辨率 + 不确定性；低频事件下"不确定性/基准率项"主导，始终预报基准率的平庸预报也拿低分但零决策价值。
  - Mellers et al. 2014《Psychological Strategies for Winning a Geopolitical Forecasting Tournament》，Psychological Science 25(5):1106-1115（2014-03-21，Tetlock 为合著者）——2 年锦标赛、top 2% 超级预测者、训练/协作/追踪同时改善 calibration 与 resolution；校准的前提是海量、可复算、可追踪的短期预报。
  - Sharpe 1975《Likely Gains from Market Timing》，Financial Analysts Journal 31(2):60-69（1975-03）——择时需远高于 50% 的胜率才不输买入持有（**精确断点未从一手原文核验，标"未验证"**）。
  - 三者共同：稀疏 / 低频 / 择时决策统计上难校准；高频中间品可校准。
  - 代码事实：`method_revision_ledger.jsonl` 空文件正是"修正方法"落点；`no_backflow` 只禁"回流 prompt"，不禁"离线修订方法台账"。
- **反驳证据**：分层可能让闭环名存实亡——决策层不承诺变好，只剩中间品打分，或又退回"文章质量"闭环，决策价值仍未闭环。
- **失效条件**：若所有者愿投入多年积累决策样本、接受"决策级校准是慢变量、可能十年才证伪"，上层可升级为统计闭环。
- **置信度**：中高（0.75）。

## 北极星候选 ×3（每句 ≤40 字）

1. **做出可靠 NDX 判断，在极少数该动手时，帮所有者做比"长期持有"更好的买卖决策。**（39 字）
2. **可审计推理链是手段：每个结论都说明对象、证据、反证与改判条件，让人敢信、敢不动。**（40 字）
3. **高频判断可评分可修正，少数重大决策如实记账、事后复盘，不承诺统计变好。**（35 字）

**取舍说明**：① 是"目的型"，忠于所有者原话（可靠判断 + 辅佐买卖决策），把"可测量变好"降为手段——**推荐作主北极星**。② 是"手段锚"，回答"怎么做到可靠"（六问），但描述的是文章质量而非决策价值，不宜单独当目的。③ 是"校准口径"，回答"变好"怎么兑现，宜作原则条款而非北极星正文。若只取一句取①；允许"目的+手段"两句则取 ①+②，③ 下沉为校准闭环的约束条款。
