# 任务书改后版 · 改动清单（2026-08-13）

> 用途：把六份并行任务书里的两处问题修掉。改动以"原 → 改"的清单形式给出，供任务书作者直接套用到自己的原文上（它手里已有原文，按清单改最不易出错）。共 4 类、9 处。

---

## 问题一：删掉任务里预设答案的"提示/定义句"

这些句子把底稿"第六节 一方观点"的结论埋进了任务，会让执行 agent 顺着已有方向走，"独立对质"失效。

### 改动 1（P2 任务 1）—— 删掉预设答案的定义句

- 原：`成功标准第一性推导：判断系统的价值 = 它改变的决策的期望价值。`
- 改：`成功标准第一性推导：判断系统的价值该用什么衡量？（自证，不预设答案。）`

### 改动 2（P2 任务 2）—— 删掉复述结论的提示与预设方向

- 原：`文章质量 vs 决策价值：何时强正相关、何处背离（提示不限于：过度追求平衡可能抑制"该出手时出手"）。`
- 改：`文章质量与决策价值的关系：正相关 / 弱相关 / 背离 / 其他？（自证，不预设答案。）`

### 改动 3（P2 任务 3）—— 删掉预设的考核对象

- 原：`……裁决：存/废/改造；若存，考核对象是每篇判断还是少数偏离默认动作的建议。`
- 改：`……裁决：存/废/改造；若存，考核对象是什么（每篇判断？偏离默认动作的建议？其他？自证）。`

## 问题二：给"联网查证"补来源分级

六份都写了"联网查证（来源+日期）"，但没规定来源等级，执行 agent 可能引用营销号/内容农场（这类来源照样能通过"10 分钟复现"）。

### 改动 4（六份全部 · 规矩一节）

在每份"规矩"的"防编造"那条之后，加一句：

`- 来源分级：实证底座来源必须分级——官方统计 / 经同行评议论文 / 权威机构报告 > 主流媒体 > 卖方研究 > 自媒体；自媒体 / 内容农场 / 营销号不得作为实证底座。`
