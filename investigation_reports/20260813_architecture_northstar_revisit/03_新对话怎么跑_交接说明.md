# 新对话怎么跑（六问并行校准 · 执行交接说明）

> 用途：让执行方在**全新对话、无历史上下文污染**的状态下跑六问。把它整段粘进新对话开头即可；六份任务书已落盘为 `P1_任务书.md`～`P6_任务书.md`，执行方自行读取，无需粘贴。
> 关键前提：本说明的存在，就是为了防"上一个对话聊出来的结论漏进执行"。执行方必须当作从没见过这些观点。

## 冷启动铁律（先读这条）

- 本对话是**干净起步**：不得继承任何历史对话的结论、观点、倾向。唯一知识来源 = 下面"必读"列出的文件 + 本说明。
- 尤其不得沿用这些**既有判断**（它们正是要被独立对质的东西，不是既定事实）："文章质量 vs 决策价值""系统缺个人决策翻译层""该不该用 DSH 当编排器""过度追求平衡会抑制出手"。你若自己从材料里推出来，可以写进备忘录；但必须是你**自己推的**，不是"记得的"。
- 你的角色是**执行 + 落盘 + 逐条核实**，不是拍板。北极星与不变原则的定夺权在所有者一人。

## 必读（按顺序）

1. `investigation_reports/20260813_architecture_northstar_revisit/01_架构校准探讨底稿.md`（问题边界；其"第六节 一方观点"是**要挑战的靶子，不是参考答案**）

3. 六份任务书：本目录下的 `P1_任务书.md` ～ `P6_任务书.md`（最终版，已含"来源分级"与"不预设答案"两处修正）

## 执行计划

- 先跑 **P6 一份**做试水（验证质量与"真独立"），所有者认可后再全跑。
- 全跑：**六份并行，互不读对方产出**。P2（目的与校准闭环）是地基、最优先；但执行可并行，验收辩论时 P2 先定。
- 每份只允许新建它自己的三个文件（备忘录 / PROGRESS / BLOCKED），落 `investigation_reports/20260813_architecture_northstar_revisit/`，其余文件一律只读。

## 交付与核实（这是"跑对"的关键，不是"跑完"）

- 每份备忘录：核心结论 ≤5 条，每条**五件套齐全**（判断对象／支持证据带来源日期或可复跑命令／反驳证据／失效条件／置信度）。
- **逐条核实，不许只信 agent 自述**：
  1. 抽每份至少 1 条外部引用去复现（10 分钟内能查到、且来源等级达标）；
  2. 抽至少 1 个代码事实去重跑命令核对；
  3. 检查 `git status` 是否只多了该 agent 的三个文件。
- 发现编造 / 凭印象 / 来源不达标 → **打回重做，不算完成**。

## 红线

- 不改 `CLAUDE.md` / `AGENTS.md` / `系统说明书.md` 任何一个字。
- 不擅自决定北极星；只产出备忘录供所有者辩论。
- **"是否用 DSH 当编排器"（T-DSH）不在此列，现在不做**——等 P2/P5 结论出来后再另行立项。
