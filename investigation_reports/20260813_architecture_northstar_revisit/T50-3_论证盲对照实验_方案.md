# T50-③ 论证盲对照实验方案（2026-08-15，开工前预注册）

> 依据：`配餐单_v0_四站条目.md` 第四节第 5 条（所有者已批准）；红队稿第四节的方法论修正全部采纳。
> 本方案在实验跑之前预注册：判分标准、主终点、样本量、失败条件都先写死，事后不得改。

## 一、要回答的问题

风险哨兵先看论点论证（B 组）相对于论证盲（A 组），是**多产出**独立有效的风险，还是**漏掉**论证之外的风险？决定"论证盲"分料是否值得长期化。

## 二、组别（两组做同一道题，同一份输出合约）

- **A 组（盲读）**：输入 = C3 上线后的 risk 分料版 `governance_input`（无任何 thesis_*；含 layer_summaries + 冲突清单 + key_evidence_refs）。提示词 = 改写后的 `risk_sentinel.md`。
- **B 组（读论证）**：输入 = critic 版 `governance_input`（含 thesis_* 全套）。提示词 = 同一份改写后的 `risk_sentinel.md` 基础上，仅把"你拿不到论点论证"一段换成"你拿得到论点论证，但你的任务是产出完整风险报告"。**B 组不附加"只找论证之外的盲区"的输出禁令**——两组都必须产出完整 `RiskBoundaryReport`；重叠由评分端事后计算，不由指令阉割（红队稿 4.2 的假阳性陷阱）。

## 三、样本

同一组真实上游产物（同一 run 的 synthesis_packet + thesis_draft），每组各跑 3 次，共 6 次 risk 级调用。若 3 次后两组差异落在噪声带内，加跑一轮后再报，不硬下结论。预算口径（已批准）：两组各一次"治理链相关站真实跑"量级；实际以跑后结算单为准。

## 四、预注册判分清单（固定，事后不改）

逐条判 `命中 / 漏报 / 误报`：

1. 七条风险边界（risk_sentinel.md：估值压缩、盈利 miss、流动性冲击、集中度崩塌、广度恶化、情绪逆转、趋势破裂）各自：状态判断是否与输入证据一致。
2. 13 种冲突矩阵中 A/B/C/K 四类必查项是否触发且归因正确。
3. `objective_firewall_summary.unresolved_tensions` 里的张力是否至少有一条进入 must_preserve_risks 或 failure_conditions。
4. 不得编造：输出中的任何数字是否能在输入材料中找到（红队稿第 6 条机器可查）。
5. 引用的 evidence_refs 是否全部合法存在。

## 五、主终点（不只看产量）

- **采纳率**：两组各自的 `must_preserve_risks` 有多少进入 `final_adjudication` 且被 run_review / 人工复核评为有用。
- **共同盲区**：两组都漏、但事后（最终判断书/人工复核）确认重要的风险——共同盲区变大才是真问题。
- 次级指标：独立风险数（A 组有而 B 组没有）、重叠率、误报率。

## 六、结论口径（先写死）

- A 组多产出独立且被采纳的风险 ≥ 有意义的差距（以 3 次重复的一致方向为准）→ 论证盲坐实，分料长期化。
- 两组无可靠差异 → 按 06 定案"再谈合并"。
- B 组（自由作答）明显更优 → 分料有净损失，回退并把证据带回给所有者。

## 七、实现位置（后续施工，不在 C2/C3 基础施工内）

在 orchestrator 增加实验开关（如 `risk_blind_experiment=True`），同一 run 内依次产出 `risk_boundary_report_blind.json`（A 组）与 `risk_boundary_report_seen.json`（B 组），正常主链仍用 A 组结果；跑完由根线程按本方案判分并写实验报告。
