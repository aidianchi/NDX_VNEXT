## 一、对质总账

**两稿共识（根线程复核后采纳）**：

1. 四站是治理链，不是重新分析原始数据的分析员；证据引用名的合法性校验只看 ref key 是否存在，与 value 内容无关——所以瘦身绝不能删 ref key 和 `allowed_evidence_refs` 清单。
2. critic 必须拿"论点论证全文 + 被引用证据的完整读数卡片"（`key_evidence_refs` 全字段），否则它那道核心必答题"论证说的和记录写的是否一致"（critic.md:71）会缺料。
3. risk 必须论证盲：不给任何 thesis_* 字段；材料 = 冲突清单 + 各层摘要 + 论证盲重建的 `key_evidence_refs`（从冲突与层摘要收集，不从论点支撑链收集）。
4. risk 盲读是"改数据 + 改提示词"的绑定手术：`risk_sentinel.md` 的"基于 Thesis dependencies 列失效条件"（L97-107）和"检查 thesis_principal_contradiction"（L148-155）两道必答题必须同批改写，否则 risk 会漏判或脑补一个论点出来攻击。
5. `GovernanceInputPacket` 现在没有 `layer_summaries` 字段，C3 必须新增；首轮 critic/risk 的 must_preserve_risks / critique / schema 默认值等空壳字段是给 reviser/final 的，首轮塞给两站是浪费（可顺手移除）。
6. 论证盲对照实验必须公平：A/B 两组都产出**同一份完整** `RiskBoundaryReport`（B 组不附加"只找盲区"的输出禁令，否则是先压低 B 组产量再比产量=假阳性）；预注册固定判分清单（7 边界 + 13 冲突矩阵 + 防火墙张力）；主终点看下游采纳与共同盲区，不只看产量；同 run 每组至少 3 次重复（LLM 单次方差大）。
7. 成本账必须重测：06 定案 L78 的"56 万"是 07-25 瘦身**之前**的基线；07-25 已把两站提示词输入压到约 14.3 万/15.9 万字符。当前真正剩下的 field_value 体量见第三节实测。

**两稿唯一实质分歧**：C2 是否整删 `field_value` 键——建设稿按 06 字面设计"整删"；红队稿主张"只删审计级明细、保留聚合统计与发言权元数据"（即 07-25 已实现的口径）。根线程实测账与裁决见第三节。

## 二、四站条目（v0 推荐口径；如你在第三节选 B，则第 1、2 站按括号内激进版执行）

### 1. counter_thesis（反方）

- **职责一句话**：在主论点诞生前，构造 1-2 个有区分力、至少一条方向对抗的反方假说，不当最终裁判。
- **必须给**：`bridge_v1_structure`（主线姿态）+ `bridge_v2_feedback_summary` + 非兜底调查报告 + `synthesis_packet_without_self_reference` 的结论层（`layer_summaries`、`bridge_summaries`、高严重度冲突、主要矛盾候选、客观性防火墙、`synthesis_guidance`）+ 全量 `allowed_evidence_refs`（94 个合法名字，一字不删）+ `forbidden_context_refs` 独立性边界。
- **证据形态（推荐 A）**：evidence_index 每条 = ref key + 父级结论字段（`metric`/`current_reading`/`normalized_state`/`narrative`/`permission_type`/`mixed_field_authority`/`source_tier`）+ 子引用身份与发言权（`field_name`/`field_authority`/`permission_type`/`source_tier`）+ `field_value` 聚合统计；**不**再携带可下钻到单票/单日的审计明细（07-25 已压缩）。若选 B：连聚合统计与父级 narrative 一并拿掉，只留"一行证据护照"。
- **不给**：`competing_hypotheses`/`hypothesis_competition_summary`/`adjudication_history`/`counter_thesis_boundary`（自我循环，代码已 pop）；`evidence_registry_summary`（阶段 4 治理专用）；事件材料（恒空=正确隔离）；`thesis_draft.json`/`analysis_revised.json`/`final_adjudication.json`。
- **禁止碰**：自行拼接清单外 ref；编造"调查发现"；重新计算原始指标。
- **回退条件**：兜底率上升（`deterministic_fallback`/`fallback_reason` 非空）→ 先加回父级 `narrative` 全文，仍不行加回 `field_value` 聚合字段；非法 ref 率上升 → 加回子引用发言权完整描述；方向对抗消失 → 加回桥接摘要完整版。

### 2. thesis_builder（论点）

- **职责一句话**：把五层摘要、桥接结论、冲突与竞争假说整合成主论点、赔率、仓位与失效条件；不是重新分析原始数据的人。
- **必须给**：`layer_summaries`、`bridge_summaries`、`high_severity_conflicts`/`high_severity_typed_conflicts`、`principal_contradictions`、`competing_hypotheses`、`hypothesis_competition_summary`、`adjudication_history`（07-27 教训：删它失效通道退化为永不触发的 AND 复合条件）、`objective_firewall_summary`、`synthesis_guidance`、`packet_meta.object_run_gate`（kernel 版）、瘦身 `evidence_index`。
- **证据形态（推荐 A）**：同反方——父级结论字段 + 子引用身份/发言权 + `field_value` 聚合统计（value/unit/coverage/windows 等），不携带审计明细。**理由**：thesis_builder.md:25-27 强制"估值/盈利/风险补偿类强结论必须引用 #FieldName 子条目、不得靠结论文字猜字段"——没有子条目的聚合统计与发言权，这条规矩失去执行前提，模型只能拿 ref 名字套层摘要编，恰好制造"看不见就编"。若选 B：按 06 字面整删 field_value，同批加三道保险（见第三节 B 档）。
- **不给**：`counter_thesis_boundary`/`evidence_registry_summary`（已 drop）；事件材料（恒空=正确隔离）；完整 object_run_gate（kernel 已够）。
- **禁止碰**：重新分析原始数据；`mixed_field_authority=true` 父 ref 撑强结论；用 technical/proxy 读数证明估值便宜/贵；编造点位、胜率、概率。
- **回退条件**：reject 不带具体反证 ref 增多 → 加回父级 narrative 全文；子引用幻觉增多（把叙述字段当合法 ref）→ 加回 `field_authority` 完整描述；`invalidation_conditions` 退化为 AND 复合条件 → 恢复 `hypothesis_competition_summary` 相关字段（07-27 同款信号）。

### 3. critic（批评者）

- **职责一句话**：攻击论点论证的逻辑漏洞与证据一致性，双向挑刺（乐观跳跃与过度谨慎同罪）。
- **必须给**：thesis 论证全套字段（main/environment/valuation/timing/dependencies/support_chains/hypothesis_responses/state/priced/payoff/time_horizon/portfolio/confirmation/invalidation/reader_conclusion/principal/secondary/price_reflection_map/confidence/retained_conflict_types）+ `high_severity_typed_conflicts` + `principal_contradictions`（Bridge 候选）+ `key_evidence_refs`（被论证与高严重度冲突引用的 ref 的**完整读数卡片**，含聚合 field_value，审计明细压缩）+ `known_data_gaps` + `synthesis_guidance` + `objective_firewall_summary`；schema 反馈仅 retry 时注入。
- **不给**：`layer_summaries`/`bridge_summaries` 全集（critic 是攻击论证，不是重新看层）；risk 的产出字段（首轮恒空）；critique 自身产出；`pricing_expectation_ledger`（supporting_only 背景噪音）；`key_event_refs`（恒空）。
- **禁止碰**：自己调数据源、凭空添加统计数字、编造反证、不设问题数量下限。
- **回退条件**：误报"ref 不在 key_evidence_refs"增多 → 扩回更宽的收集范围；不再能发现选择性引用 → 证据包扩回 evidence_index 全集（仍压缩审计明细）；开始凭记忆补数字 → 查证据包里是否缺该数字，缺则加回对应 ref 聚合字段。

### 4. risk_sentinel（风险哨兵，论证盲）

- **职责一句话**：不看论点论证，从证据面与冲突面独立列失效条件、七条风险边界与双向成本；只预警，不判断。
- **必须给**：`layer_summaries`（C3 新增，五层摘要=risk 的事实面）+ `high_severity_typed_conflicts` + `principal_contradictions`（Bridge 候选）+ `unresolved_questions` + `key_evidence_refs`（**论证盲重建**：从冲突 evidence_refs 与 `layer_summaries.indicator_refs` 收集，不从 thesis 支撑链收集；条目与 critic 同形：完整读数卡片含聚合 field_value）+ `known_data_gaps` + `objective_firewall_summary`；schema 反馈仅 retry 注入。
- **不给**：全部 thesis_* 字段（含 thesis_principal_contradiction、thesis_dependencies）；critic 产出；risk 自身产出字段；`evidence_registry_summary`/`pricing_expectation_ledger`（提示词未列）；`key_event_refs`（恒空）。
- **禁止碰**：论点论证、critic 产出、事件材料；编造胜率/回测/样本/概率/点位/跌幅/估值倍数阈值；把"风险存在"写成"赔率不利"。
- **提示词绑定改写（C3 同批）**：输入清单（L19-33）删 thesis_* 行、加 `layer_summaries`；"失效条件检查"（L97-107）改为"基于冲突清单 + 各层摘要列失效条件"；"主要矛盾检查"（L148-155）改为"检查 Bridge 候选主要矛盾与高严重度冲突是否被证据支持、缺了哪条风险边界"；其余统计约束、冲突矩阵、输出格式不动。
- **回退条件**：`must_preserve_risks` 空洞/无 ref、`boundary_status` 缺键、`failure_conditions < 2` → 先扩回更完整的层摘要字段或证据全集；开始编统计 → 证据包扩全集或补聚合字段；对照实验显示盲读组被终审采纳率显著更低 → 分料本身有净损失，按实验结论处置。

## 三、C2 唯一待你拍板的分歧（两档，附根线程实测账）

真实账（2026-07-25 真实跑，字符数为 prompt 序列化口径；token 精确数未证实，本机无 tokenizer）：

- 07-25 瘦身前：thesis 包 518,835 字符、counter 包 534,150 字符（= 06 定案说的"56 万"量级）。
- 07-25 瘦身**已经施工并在线**：thesis 包 → 142,867 字符、counter 包 → 约 159,000 字符。**"56 万→15 万"的大头已经入账。**
- 当前包里剩下的 `field_value` 只有 16,987 字符；整删后 thesis 包 → 125,081 字符，**再省 12.4%**；counter 侧约省 11.7%。
- 这 16,987 字符里，顶层聚合统计（value/unit/coverage/windows 等）约 2,556 字符，其余为各字段的短数值与结构化统计（07-25 已把超长审计明细压成摘要）。

**A 档（根线程推荐，红队稿主张）**：维持 07-25 口径——删审计级明细、保留聚合统计与发言权元数据。C2 的收口变成：机器测试锁死"证据包必须保留聚合统计、不得整删 field_value" + 实测省幅与当前基线写入 WORK_LOG + 沿用 06 的回退闸门。**代价**：不再多省那 12%；**收益**：不冒"读数在眼前、底稿不可查"的假精确，thesis 的 #Field 引用规矩保持有执行前提。

**B 档（06 字面）**：整删 field_value，两站只留"结论级字段 + 一行证据护照"。**代价**：再省 12.4%/11.7%；**风险**：红队判定会制造"看不见就编"高发区，且必须同批加三道保险——①提示词加"current_reading 是 L1-L5 转述、technical 不得证明估值、proxy 不得冒充官方"红线；②生成期闸门补两条机器检查（估值强结论只引 technical/proxy、mixed 父 ref 撑强结论即打回）；③六项回退指标（结构通过率、非法 ref 率、反方兜底率、失效通道 AND 退化、越权引用率、risk 空洞率）上线即监控。保险本身是新增工程，不在 06 清单内。

根线程判断：**A 档更符合"先判断、最小修改"与"省钱不能以牺牲证据链为代价"**；B 档的 12% 相对两站全链成本占比很小，而它要求的新保险工程比省的还贵。T38/T45 的"等 C2 实测省幅"也以 A 档实测为准即可。
