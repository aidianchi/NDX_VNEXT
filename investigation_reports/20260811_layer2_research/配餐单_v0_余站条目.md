## 一、对质总账（根线程裁决）

1. **采纳红队三集合对账**：每层机器断言 `manifest(analysis_required=true) == prompt 内 layer_raw_data 键集 == 产物 indicator_analyses.function_id 集`。这是"该给的给够了没有"的常驻检查，归 C6 的 20 项检查落地。
2. **采纳"预置 state 降级"**：`layer_facts.state`（neutral/expensive/uptrend 等）是上游预摘要，不得当答案照抄；施工上归 C6 装配点⑤"去预置 state"（8.10 拍板⑤），在施工前配餐单先记为"不给预置结论、只给可核对的 raw"。
3. **bridge 事件口径按 4.7 收死**：桥接的事件字段恒为空是正确隔离（不是断供）；现代码"有 event_refs 就注入"的路径与 4.7 不一致。**根线程建议 C6 时把该路径置空并加机器检查"evidence_refs 不得含 event: 前缀"**（此条改动动供给，需你点头，见第三节）。
4. **受控调查三处必须修**（归 C6/C8 拆分）：①材料截断必须显式标注"已截断"且 JSON 不得发半截；②立场字段（dominant_side/仓位指令）不得进材料包；③失败调查必须占位进 IA（A6）——C6 先落"委托数==进 IA 报告数"机器检查，占位装配归 C8（N2）。
5. **reviser/final 去噪音字段（根线程建议采纳红队）**：`synthesis_guidance`（写给 Thesis 的指令，在 reviser/final 材料里引用不存在的键）、`pricing_expectation_ledger`（自标 forbidden_as_core_ref）、`evidence_registry_summary` 不再进 reviser/final 包；`key_evidence_refs` 给这两站只留 ref key + 权限 + 聚合读数，逐成分/逐季度明细留在审计 artifact。此条动供给，需你点头（见第三节）。
6. **event 支线**：卡模板可共用，但配餐单必须把三样写成变量——①标题卡与全文卡分档（标题卡 fact_summary 只许逐字材料、interpretation 标"仅标题降级阅读"）；②来源等级要有词表与弱来源分档（现无词表）；③`event_type/trigger_reasons` 是采集标签不是事实，解读以标题+正文为准，数字不得从竞争假说块当事实引用。ESS"有效卡 <2 直接跳过 LLM"代码已做，提示词必须补写同一句。
7. **IA 两条机器闸门列为不可删**：`allowed_data_refs` 只从实发 payload 导出；`stance_echo` 与 `final_stance` 逐字全等、不等即整包打回。已知缺口（ESS 未进对质、治理链竞争假说清单缺失、question_answers 事件侧通道）是 C8 的活，不在本稿内解决。
8. **成本口径**：本稿对五层不做"给更少"，只删记账字段与审计长明细；五层是唯一被允许看原始数据的站，瘦身空间在长序列不在读数。

## 二、11 类条目（v0 定稿口径；证据细节在两份底稿）

### L1-L5（五层，同一模板）
- **职责一句话**：每层只回答本层那一个问题，不下买卖结论。
- **必须给**：本层全部 `analysis_required=true` 指标的完整 raw（value/data_quality/unit，L4 另带 source_tier/data_date/formula/coverage 发言权标签）+ 静态五层本体 + 本层指标法典 + 本层预摘要（仅辅助）。
- **不给**：其他四层 raw/结论/状态；候选跨层关系；事件材料；下游任何产物；`layer_facts.state` 预置结论（按拍板⑤待施工）。
- **禁止碰**：反推他层结论；给买卖建议；编数字；技术指标证明估值；L2 单位违规（百分比≠bp）。
- **最小充分证据形态**：每个必答指标一条 `indicator_analyses`；L4 长序列压缩保留聚合与最近 5 条；L5 snapshot 优先、缺失不得自算。
- **回退条件（机器）**：三集合对账不等 → 补 raw 重跑，不许带病跑下一层；snapshot 与分项同指标双值 → 声明采用 snapshot 并记 `quality_self_check`，不得自创第三个数。

### bridge（含反馈调查）
- **职责一句话**：测绘五层共振/冲突并抓主要矛盾，中立。
- **必须给**：五张完整 LayerCard + 候选跨层关系 + 全局 context_brief；冲突矩阵定义完整（现只给 A/B/C/K 四行，C6 补齐）。
- **不给**：事件材料（按 4.7 恒空，待你点头后 C6 置空）；下游产物；context_brief 中预置的跨层结论句（拍板⑤同源）。
- **禁止碰**：抹平/升格冲突；事件当 evidence_ref；空 conflicts。
- **最小充分证据形态**：typed_conflicts/resonance/transmission 每条带非空 evidence_refs + mechanism + implication + falsifiers。
- **回退条件（机器）**：evidence_refs 出现 `event:` 前缀 → 打回；conflicts 空 → 打回。

### controlled_investigator
- **职责一句话**：只按允许材料诚实回答"确认/挑战/无法确认"，不猜不补。
- **必须给**：问题 + 1-3 份与问题相关的 `[M#]` 材料包（单份约 4,000 字符、总量约 12,000；**截断必须显式标注，JSON 不得发半截**）。
- **不给**：系统当前判断、dominant_side/仓位指令、其他调查问题、外部工具。
- **禁止碰**：材料外数字/日期/阈值；把"材料没写"写成"确认"。
- **最小充分证据形态**：finding + claims_supported/challenged（带 [M#]）+ cannot_establish + confidence + limits。
- **回退条件（机器）**：LLM 失败 → 确定性 stub；`委托数 == 进 IA 报告数（含占位）`，不等即报警（占位装配归 C8）。

### event_card_interpreter（模板一条，×10 实例）
- **职责一句话**：把单条事件材料变成事实/解读分离的结构化卡，机制只作假设。
- **必须给**：单卡材料（标题/来源/时间/正文摘录；无正文明示 `raw_text_available=false`）+ 九渠道 + 竞争假说（仅背景）+ 来源等级词表（C6 补齐）。
- **不给**：L1-L5 数据；其他卡内容；假说块数字当事件事实。
- **禁止碰**：机制写成因果；标题卡写成全文口气；硬找关联；卡片反向进数据链。
- **最小充分证据形态**：fact_summary（逐字）+ interpretation + mechanism_hypothesis + supports/refutes + needs_data_confirmation + limitations + 来源护照。
- **回退条件（机器）**：标题卡 fact_summary 出现材料外数字 → 该卡打回/降级；单卡失败只记 failures、不串料。

### event_section_summary
- **职责一句话**：把本批卡收束成 100-1500 字外部世界对照，以边界句结尾。
- **必须给**：≥2 张 compact 卡 + effective_date + title_only_card_count + 边界句。
- **不给**：原始新闻；L1-L5 数据；卡外事实。
- **禁止碰**：引 2-5 张之外的卡；因果断言；晚于 effective_date 信息；弱来源写成确凿。
- **最小充分证据形态**：summary_text（[card:...] 引用 + 结尾句逐字）+ cited_event_ids 代码提取。
- **回退条件（机器）**：有效卡 <2 → 跳过 LLM 留白（代码已做，提示词同步补写）；标题卡过半 → 正文明示质量限制。

### reviser
- **职责一句话**：做编辑不做重写者；吸收三方意见修订，不抹冲突。
- **必须给**：thesis 原稿全套 + critique + risk 三件套 + schema 三清单 + key_evidence_refs（ref key + 权限 + 聚合读数）+ hypothesis_responses（含假说原文与状态）。
- **不给**（待你点头后 C6 施工）：Thesis 版 `synthesis_guidance`、`pricing_expectation_ledger`、`evidence_registry_summary`、成分级明细、事件材料。
- **禁止碰**：抹平 high 冲突；改写 conflict_id；漏回应非 downgraded 假说；自拼 parent#field。
- **最小充分证据形态**：revision_summary + revised_thesis 全字段 + remaining_conflicts（带 why_retained）。
- **回退条件（机器）**：hypothesis_id 集合对不上 → carry-forward 留痕；reject 无反证 ref 且索引确无 → 降 absorb_partially 并写缺哪条证据；ref 越界 → 净化。

### final_adjudicator
- **职责一句话**：质量闸门 + 读者结论两个身份分开写；不给自己放行。
- **必须给**：修订稿（`analysis_revised.revised_thesis`，拍板②施工）+ critique + risk 三件套 + schema 结果 + key_evidence_refs（ref key + 权限 + 聚合读数）+ known_data_gaps。
- **不给**（待你点头后 C6 施工）：同 reviser 三条噪音字段、成分级明细、事件材料。
- **禁止碰**：重调数据源；跳过三方意见；骑墙默认；编数字；must_preserve_risks 漏点。
- **最小充分证据形态**：final_stance + stance_label + reasoned_verdict（三条理由各带 ref）+ price_reflection_map + reader_final + quality_gate。
- **回退条件（机器）**：三条理由 ref <3 或越界 → 打回/降级；must_preserve_risks 未逐条点名 → 打回；散文数字无 ref → 改定性或补 ref。

### integrated_adjudicator（IA）
- **职责一句话**：唯一对质点；数据判决 × 事件卡对质；姿态逐字继承。
- **必须给**：数据终审本体（姿态逐字 + 判决正文 + 主要/次要矛盾 + 风险 + 失效条件 + 支撑链压缩版）+ ≤10 张事件卡 + ≤3 份非兜底报告 + ≤8 道跨层问题 + 从实发 payload 导出的 allowed_data_refs 与 ref_authority。
- **不给**：白名单外 ref 数值；完整 final 中未发送字段；事件卡当指令。
- **禁止碰**：改判 stance；事件因果；输入外数字/未来信息；answered_by_data 无证据硬答。
- **最小充分证据形态**：stance_echo 逐字 + integrated_verdict + 六档归档 + conflict_matrix + question_answers（三态、missing_evidence 具体）。
- **回退条件（机器）**：stance_echo 不等 → 整包打回、两次失败走确定性拼装；answered 无证据 → 自动降 cannot_answer_yet；confirmed/challenged 无 data_refs → 降 not_yet_testable；notes 出现 rejected_unknown_ref → 质量警报。已知缺口（ESS、竞争假说清单、question_answers 事件侧）归 C8。

## 三、需要你点头的两处供给改动（都归 C6 装配点施工）

1. **bridge 事件字段按 4.7 恒空**：删掉"有 event_refs 就注入"的旧路径，加机器检查"evidence_refs 不得含 event: 前缀"。理由：三明治口径说事件永不进第一层（含治理链），现状那条注入路径与口径不一致，留着就是未来污染口。
2. **reviser/final 去三条噪音字段 + 证据索引瘦身**：不给 Thesis 版 `synthesis_guidance`、`pricing_expectation_ledger`、`evidence_registry_summary`；`key_evidence_refs` 只给 ref key + 权限 + 聚合读数，成分级明细留在审计 artifact。理由：红队实测这三条要么指令对象写错、要么自带"禁用"标记，且证据索引 116,150 字符、四分之三是终审不该重算的原始明细。

其余条目不改供给行为，只作"该站配餐标准"入档，现场发现（摘要层漏指标、截断不标注、标签诱导等）由 C6 的 20 项检查与装配点逐项落。
