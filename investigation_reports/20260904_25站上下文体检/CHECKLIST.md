## 检查项

### A. 顺序（材料编排）

- **A1 段落编排**：把 prompt 当一份会议材料看。任务定义 / 输出要求 / 纪律规则出现在什么位置？重要指令是否被埋在大段数据中间（长上下文的注意力洼地在中段）？输出字段规格离任务描述远不远？
- **A2 数据时序**：运行时数据里时间序列的排列方向是旧→新还是新→旧？最新数据点在开头还是末尾？有没有把过期段落排在前头冒充"当前状态"？
- **A3 few-shot 打断**：示例（Example: get_xxx）插在什么位置？是否把「任务定义 → 数据 → 输出要求」的主干切成碎片？
- **A4 重试差异**（仅 final_adjudicator 等多 attempt 站）：对比 attempt_1 与 attempt_2 的投影，重试时上下文是「只补更正信息」还是「整套重发」？多发的字节里有多少是重复？

### B. 体量与冗余

- **B1 体量账本**：报告 prompt 总字符中，各段落占比（用投影头部段落目录现成的数字）。最大的 3 段是什么、对「模型做出正确判断」各有必要吗？判据：这段删掉，判断会变差吗？
- **B2 站内重复**：同一份数据（同一指标数值、同一段事实）在 prompt 里出现了几遍？典型嫌疑：原始数据（layer_raw_data）、事实摘要（layer_facts）、上下文简报（context_brief）三层是否互为复读。用具体数值举例（同一数字出现在哪几个段落）。
- **B3 粒度错配**：长行情序列（几十/几百行同构记录）模型真正需要的是 min/max/最新值/变化率。逐行全量 dump 是不是把「预处理该干的活」推给了模型注意力？

### C. 质量

- **C1 指令冲突**：不同段落的纪律/要求有没有互相打架？（例：「必须保留冲突」vs「必须给明确方向」；「不得编造数字」vs 输出规格强制填定量字段）逐条列出冲突对，引用两边原文。
- **C2 死指令**：prompt 要求模型填的字段/做的动作，输出里真的有、下游真的消费吗？抽查 3-5 个字段：输出里有 → 算活；输出规格里有但输出文件结构对不上 → 死指令嫌疑。
- **C3 黑话词典**：清点 prompt 里的**内部代号**（本系统自造词。基准：通用金融术语如 VIX、ERP、OAS 不算；系统自造的代号如「三明治口径」「门脸」「4C」「恒空」算）。每个代号记录：首次出现位置、出现次数、**首次出现时上下文有没有足够解释**（一个新加入的分析师模型能否只凭 prompt 看懂）。无解释的列入「传染源」。
- **C4 数据新鲜度**：运行时数据里的数据日期 / effective_date 与「本次分析时点」的关系。有没有明显过期数据未标注、或字段名暗示"当前"但值是旧的？

### D. 隔离

- **D1 越权扫描**：本站按层间隔离宪法**不该看到**什么？（L1-L5 不该看到其他层的 card / 结论 / 跨层信号；thesis 之前各站不该看到 final 的判断；分析站不该看到个人决策档案 / 黄金坑清单）。在投影里搜关键词（`final_adjudication`、`thesis_draft`、`browser_sidecar`、`user_decision_profile`、`golden_pit`、其他层 layer card 路径、`apparent_cross_layer_signals`），命中了引原文判断是真越权还是仅元数据提及。

### E. 输出端闭环（验证「材料 → 输出」因果）

- **E1 叙事字段体检**：读本站输出 JSON 的**叙事字段**（给最终报告读者看的散文：finding、narrative、reasoned_verdict、one_liner、summary、conflicts 描述等，以输出规格为准）。逐项检查：
  - **黑话传染**：叙事散文里是否直接使用 C3 清单里的内部代号且未给读者解释？
  - **复读机检测**：叙事字段里是否有 ≥15 个连续字符与 prompt 某句完全相同（模型在背题而不是作答）？抽 5 句核验。
  - **簿记语言密度**：叙事散文里字段名 / ref / ID / 枚举值这类机器语言出现频率，是嵌在因果链里服务判断，还是裸列？
  - **长度纪律**：输出规格对叙事字段有长度要求吗？实际输出守了吗？
- **E2 因果对**：综合 A-E，本站有没有「材料的某个具体缺陷 → 输出的某个具体毛病」能连成因果的？能连的写成一對（材料证据 offset + 输出证据字段）。连不成就明说「未发现因果」。

## 严重度定义

- **P0**：可能误导投资结论（越权信息进了上下文、指令冲突导致输出自相矛盾、关键数据被时序倒置）
- **P1**：明显浪费或传染（大段冗余搬运、黑话直出无解释、复读机输出）
- **P2**：可优化（顺序不优、粒度可再预处理、措辞可更准）

## 纪律

- **只读分析**：除你自己的报告文件外，不得修改/删除任何文件。不跑任何写操作命令。
- **证据驱动**：每个判定必须带证据（原文片段 + offset 或行号）；拿不准就写「存疑 + 需要什么才能定」。
- **不恭维**：没有问题就写「未发现」，不要硬凑。
- 数字要真实：引用的字符量、次数、日期必须来自你实际读到的内容。
