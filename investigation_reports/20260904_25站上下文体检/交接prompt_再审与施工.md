## 前任四条教训（直接继承，别再踩）

1. macOS BSD grep 不认 `\|` 交替——用 `grep -E` 或 ripgrep，否则出三连空假阴性。
2. 验证内容传输别拿 JSON 序列化串当探针（下游重渲染后必假阴性）——用数据原文片段做探针，字段名级 → payload 级 → prompt 渲染级三层验。
3. 文件编辑报成功 ≠ 落盘——逐处回读验收（本仓库发生过多次）。
4. 「浪费 / 死链路」类结论先过三关再出口——设计意图常在《系统说明书》和 `contracts.py` 里白纸黑字。
