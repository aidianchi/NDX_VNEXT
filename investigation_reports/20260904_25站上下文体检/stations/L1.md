## 修复建议

1. **对应 P1（raw_series）**：把 `raw_series` 从 prompt 移出（留 payload.json 或按需引用），prompt 内保留 `path` 数组 + `slope_12m/cuts_priced_bps/state` + `liquidity_thresholds`。可省约 23k 字符（30%），fed_path 块从 44.2% 降到约 14%。
2. **对应 P2（data_quality 样板）**：每指标只保留 `as_of/effective/data_date`、`source_tier` 与**非默认** anomalies；methodology/formula 去重取一；四个默认 anomaly 收敛为一句「其余字段为默认值」。约省 6k 字符。
3. **对应 P2（三处重复讲授）**：将 IndicatorCanon 与 Indicator Semantics / Mechanism Grammar 合并为单一「按指标」块（每指标一段：语义 + 机制链模板 + 发言权边界），预计省 3–4k 字符。
4. **对应 P2（trend 语义漂移）**：`layer_facts` 中 MA 类指标的方位字段更名为 `position_vs_ma`，或统一换算成输出枚举口径，避免模型自行翻译。
5. **对应 P2（舍入伪影）**：copper_gold 的 ma50 提高精度或按未舍入值计算 position_vs_ma。
6. **对应 P2（双刻度）**：全链路统一百分位为 0-100，raw relativity 不再输出 0-1 刻度。

## 对照基准（供其他大站参考）

L1 作为 7.7 万字符"轻量站"，以下结构要素是"刚好"的，可作其他站的对照：

1. **few-shot 前置且不打断主干**：4 例共 3.4%，集中在任务定义之前的导语区，且明示「不要复制数值」——示例位置与体量都没越界。
2. **输出规格 + Response Rules 紧贴 prompt 末尾**：形状规则处于近因位置，输出形状 100% 合规。
3. **数据块"最新值在前 + 日期字段齐全"**：每指标 value 首字段即最新读数，data_date/effective_date/as_of_date 三件套完整。
4. **时点纪律显式声明**：context_brief data_summary 一句话讲清"月度指标滞后属正常"，堵住了 C4 误报。
5. **隔离宪法三处重申且输出零越权**：System 约束 / 静态五层本体 / Context Boundary 相互呼应，输出 notes 自证未越权。
6. **叙事文风约定带操作定义**（「数字嵌在因果链里、不陈列」「簿记语言住结构字段」），输出端完全守约。

其他大站若叙事字段出现黑话直出或复读机输出，应优先对照本站第 6 条检查其是否缺少带操作定义的文风约定；若出现形状违规，对照第 2 条检查输出规格是否被数据挤离末尾。
