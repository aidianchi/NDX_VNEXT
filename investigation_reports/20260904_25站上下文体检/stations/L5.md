1. **（对应 P1）削 Runtime Input 簿记**：`layer_raw_data` 各 payload 只保留 `value` + `date` + `unit` + 一份 notes；`data_quality.methodology/formula` 与 notes 三处同文合并为一处，anomalies/collection_duration_ms 等采集元数据移出模型上下文（落审计日志即可）；`layer_facts.summary` 与 `context_brief.layer_highlights` 二选一。预计 Runtime Input 可缩 30-40%，判断力零损失。
