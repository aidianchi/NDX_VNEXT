# 04 照镜子：一期巡逻产出 vs 顶级标尺的差距分析（2026-08-24）

> 对照物：本目录 `benchmarks/` 十篇拆解（Cahn 缺口系列 / GS 多空同刊 / JPM Cembalest / Coatue 记分卡 / SemiAnalysis 债务结构 / 刘高畅金句 / 长江"AI 的 1998" / 费雪方法论视频 / 中金坐标系 / 华泰 capex 框架）。
> 被照对象：一期 AI capex 真巡逻（`output/event_research/runs/EV-20260823-7e9c93_20260823T163200Z/`，7 张卡 + 8 条线索）。

## 〇、一句话结论

**我们的产出是"带出生证的报道拾贝"，顶级研报是"框架 × 时间序列 × 可证伪预测"。事实纪律（逐条对账、来源分级）我们已达标甚至超过部分标杆；差的是框架、序列和判决时钟这三样深加工。**

## 一、结果差距

- 我们的 7 张卡：7 条独立的"某月某日某社报道了某事"，全部单一来源（CNBC），信息止于"报道存在"。
- 标尺的信息密度：Cahn 一条"收入缺口恒等式"年检四次（$200B→$600B→$840B→$1.5T），每期只更新输入——**同口径序列本身就是结论**；华泰一张逐厂 capex 季表（4115 亿→7739 亿→1.02 万亿）承载了我们 7 张卡都装不下的判断原料。
- 直白说：我们巡逻带回的是"食材"，顶级研报端上桌的是"菜"。这不是调研深度的差距，是**产出形态**的差距——我们只走到"采集"，没走到"结构化积累"。

## 二、逻辑差距

- **没有框架映射**（设计稿能力 C5，未实现）：标尺篇先把叙事翻译成一个可复算的结构（缺口恒等式 / ROI 桥 / 需求乘法 / 债务担保结构），再往里填数字；我们的卡没有"这条事实映射到哪个框架的哪一格"。
- **没有反方并置的结构保证**：GS 把多空分歧分解到具体参数差；费雪视频先立最强反方再反驳。我们的卡有 interpretation 字段，但没有"最强反方一句话"的必备位——证据面均衡目前靠出题时的措辞，不靠结构。
- **没有判决时钟**：标尺篇全部带"何时验证、什么信号算错"（JPM 的 12-18 个月、GS 的检验时点、费雪的胜负手斜率）；我们的卡连"改判条件"字段都没有。

## 三、方法差距

- **单一来源档**：7/7 卡全部 CNBC（主流财经转述）。标尺全部直奔一手：财报原文、债券利差、官方 deck、贷款市场结构。官方披露档 08-24 才加进白名单，这次巡逻还没用上。
- **没有时间序列化**（C7 未建）：同口径跨期积累是十篇标尺的共同底色；我们的账本会记议程，但产出物之间没有"同一对象的上期值"。
- **没有缺席信号栏目**（C3 只有雏形）：GS/Cahn/SemiAnalysis 都把"该发生没发生"当正式证据入账；我们的 needs_data_confirmation 是它的雏形，但只是免责字段，不是证据栏目。
- **材料边界自觉我们反而强**：费雪视频数字全无出处且有事实错误、刘高畅零举证——我们的对账器+镣铐在事实纪律上已超这两篇。这是要守住的资产，不是可以放松的地方。

## 四、改进工单（按杠杆排序，转 T60 后续施工）

| # | 改进 | 对应能力 | 形态 |
|---|---|---|---|
| G1 | 巡逻产出加"叙事状态"层：每次巡逻除了卡，强制产出一段"本主题当前的框架坐标"（如 capex 缺口最新值、多空最强论据各一句、改判条件） | C5 | persona + 产出格式扩展（payload 加 narrative_state 段） |
| G2 | 跟踪名单：同一对象（如 hyperscaler capex 指引、AI 收入缺口）跨 run 序列化——runner 开跑前把该主题上期值喂进 prompt，本期产出必须更新同一口径 | C7 | agenda 账本加 tracking 形态 + runner 读历史 |
| G3 | 缺席信号栏目：巡逻 prompt 固定一问"该发生而没发生什么"，进 leads 或独立字段 | C3 | persona 提示词 |
| G4 | 卡加可选字段 `falsification`（什么信号出现就改判）与 `counter_one_liner`（最强反方一句话）——可选不强制，防"形式拒收内容" | 均衡/可评分 | card schema 扩展 + 镣铐校验放行 |
| G5 | 白名单升级（另见 05）：transcript 源、独立研究源、信用数据锚 | C1 | config 调整，报老板 |
| G6 | 一手率进 run_summary：官方+官方披露档来源占比成为五项度量的过程指标 | 度量 | runner 统计 |

**新形态首跑追加发现（2026-08-24 实测）**：

| G7 | 对账覆盖不到叙事层：narrative_state 与 charter_feedback 里的断言没有出生证核对——首跑的宪章反馈虚构了"IR 域不可抓"（实测白名单正常放行）| 防编 | 后续：对叙事层关键断言也要求指回卡或抓取记录 |

**明确不做**：不追求一次巡逻写出一篇"完整研报"——研究部的定位是材料供应商，框架化做到 G1/G2 的深度即止，成文判断仍是 IA 的事。
