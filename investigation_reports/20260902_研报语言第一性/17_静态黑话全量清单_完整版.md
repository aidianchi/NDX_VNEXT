## 二、判定方法（可复现，不靠我拍脑袋）

脚本 `scripts/static_jargon_scan.py`，三个提取器：

| 提取器 | 原理 | 为什么可靠 |
|---|---|---|
| **A · 比喻词** | 这套黑话的共同成因是**从物理世界借词**（桥/垫/墙/锚/水位/闸门/承重/地心引力）。凡命中这批字符的中文词，即高危候选 | 直击成因本身。字符集**必须收窄**——早先版本混入 度/量/数/力/率/线/道 后，把"数据/趋势/指标/利率"全捞进来了，那是误报 |
| **B · 引号词** | 作者自己在用引号标记「这是个词」 | 作者的自我标注，置信度最高 |
| **C · 范文差集** | 静态源 ≥3 次、14 号范文正文 **0 次**、且已漏进报告 | 用人工好文本当干净基准。必须加"已漏进报告"这一条，否则会捞进"必须/不得/是否"这类指令用词 |

**脚本管筛选，不管判意思**：候选词是真术语、纯技术定义还是自造比喻，由人工分档（第三节）。

**计数口径说明**：第三节表格里「静态源处数」来自全语料扫描（624,291 字），「出处」列的行号来自对具体文件直接检索，两者基数不同，**数字会略有出入，属正常**，不影响定性。

**一个方法论提醒**：中文 n-gram 切词会产出碎渣（"要矛盾""率垫""盾候选"）。本文只采信**能独立成词**的条目，碎渣全部丢弃并在此声明，不拿它们充当"发现"。

**这是本文最重要的发现，16 号完全没有覆盖。**

## 五、怎么改（老板问的第二个问题）

### 第 1 类 · 换示例（**主力，收益最大，也最容易做**）

**原理**：模型不听话，它模仿。所以**改一句示例，胜过加十条禁令。**

**动作**：
1. `src/prompt_examples.py`（64,608 字）—— 全量通读，把"地心引力""垫子""温度计"这类类比换成**能落到数字的说法**：
   - ✗「10年期实际利率是成长股估值的真正'地心引力'」
   - ✓「10年期实际利率是成长股估值的关键折现率输入：它每上升 1 个百分点，同样盈利下的合理估值就下降约 X%」
2. `orchestrator.py:8066` 的「结构示例」占位句 —— 现在写的是"把读数、趋势与分位压缩成一句本层判断"，**换成一句读者能懂的示范**：
   - ✓「本层最核心的一句结论。先给白话结论，再把支撑它的数字放上去。」
3. `contracts.py` 的字段 description —— 逐条改写，把"共振或降噪"换成"互相印证或排除噪音"（**"矛盾"保留，见 2026-09-11 裁决**）。

**代价**：示例数量大（`prompt_examples.py` 6.4 万字），要全部过一遍。**但这是唯一能同时治甲类和乙类的动作**——种子语域换了，造词习惯会跟着变。

### 第 2 类 · 换措辞（机制词与比喻词，按 3.1 / 3.2 表逐条替换）

**原则**：只换**读者面**的词，**字段名和代码内部名一个字不动**（动字段名会破合约、破测试）。

**一条自检尺子**（16 号立的第四判据）：换成大白话信息有没有损失？
- 零损失 → 换（锚→主依据、张力→冲突、读数→数值）
- 换不了 → 留（安全垫、兑现、反证、判读）
- 它不是人话 → 删（绝对水位、索引、落盘、巡逻）

### 第 3 类 · 装配层不印（**不是改语料能解决的**）

页面上出现的**字段名、闸门警告、站名、编号**，全部属于这一类：
- 「证据发言权」「不能越权证明什么」这类字段名
- 「不用于判读」「不得引用」这类给模型看的警告
- "L4·NDX Earnings Revision Metrics"这类站点标签
- 「绝对水位」这类字段标识

**注意**：这一类和本轮语料改造**必须分开做**。理由：重跑一次全链**测不出它**——它压根不经过模型。混在一起改，出了问题分不清是谁的功。

### 第 4 类 · 减负（治乙类唯一有效的办法）

乙类词是模型**现场造**的，源头没得改。它们出现的原因是**一个生成单元被要求同时答好几件事**，模型只能靠造词把更多意思塞进一句话。

**动作**：一个生成单元只答一件事（15 号 §2.2 的合同减负）。
**证据支持**：06 号那份**同一次 run 内的对比**——小字段写出全场最好的人话，大字段写成天书。

### 明确不做（我已经记牢，不再提）

渲染时替换 / 禁用词黑名单 / 把私词写进提示词禁令 / 词表替换。**这四条我一次都不再提。**

## 六、必须说清的两个风险

1. **改词可能伤到分析口径。** 例如"锚"在系统里是**数据源主次分工**的术语（谁说了算），改成"主依据"语义等价，但要逐句确认。任何一条改完后，必须能回答："改完这句话的判断含义变了吗？"
2. **静态源只占一半。** 19 万字的工具函数 `notes` 里灌的是**英文公式和内部状态串**（`"NTM EPS = w*FY1 EPS + (1-w)*FY2 EPS…"`、`"Upstream data source returned None."`、`"component model disabled"`）。这不是黑话问题，是**机器语言进模型视野**的问题，会让模型跟着写技术腔。**属于另一件工单**，本文只记录，不给方案。
