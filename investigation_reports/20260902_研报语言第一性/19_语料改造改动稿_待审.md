### A1 · 治「近端 / 远端」——**不是删词，是给裸字段补中文名**

**先纠正我自己**：17 号把"近端/远端"整体判成"材料里长出的比喻词"，**只对一半**。实测发现它是**两个完全不同的东西共用了一个词**：

| | 出处 | 真实身份 | 处置 |
|---|---|---|---|
| 期限结构的近端/远端 | `tools_L2.py:577/586/625`（VIX 期限结构）、`tools_L1.py:249`（Fed funds 期货月份口径「近端（0-6月）」） | **业内真术语**（front end / back end of the curve），且 `tools_L1.py:249` 自带括号解释——**好样子** | **不动** |
| 财年口径的近端/远端 | 报告里那句「兑现桥的近端宽、远端窄」 | **`0y`/`+1y` 的外号**，业内真名是 **FY1 / FY2** | **治** |

**病根找到了**：`src/tools_L4.py:7921-7925`

```python
breadth_block = {
    "value": {
        "0y": breadth_periods["0y"]["value"],
        "+1y": breadth_periods["+1y"]["value"],
    },
    "unit": "percentage_points",
```

**字段是裸的 `0y` / `+1y`，一个中文名都没有。** 模型要指它，无话可说，就借了"近端/远端"来叫。而**它自己其实知道真名**——L4 分析员在原始产物 `synthesis_packet.json` 里写过「30日修正广度：**近端FY1**净+62.4pp、**远端FY2**净+40.5pp」，真名写出来了，到页面被丢了。

**改法（两条）**：
1. `src/tools_L4.py:7921` 的 `breadth_block` 加中文名映射：
   ```python
   "period_labels": {"0y": "当年盈利（FY1）", "+1y": "次年盈利（FY2）"},
   ```
   ⚠️ **动手前必须先验证**：契约是否允许多键（避免下游解析报错）。这是本文唯一需要先验证再改的条目。
2. `src/agent_analysis/prompts/l4_analyst.md` 涉及该指标的段落，统一写「当年（FY1）/ 次年（FY2）」。

**为什么不用禁令**：给真名比禁外号有效。**模型有真名可用时，不会去造比喻。**
