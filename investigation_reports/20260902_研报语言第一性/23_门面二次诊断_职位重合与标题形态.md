## 4. 铁证二：两个标题都不是判断句

### 4.1 范本参照只有一份能用

`exemplars/` 四份里，只有张忆东那份是**中文卖方研报**，其余三份是英文备忘录 /
致股东信体例（Marks《Sea Change》两词、Buffett《Chairman's Letter》是固定栏目名），
标题形态不可比。所以标题纪律只能以张忆东那份为准：

> **国际秩序重构危中有机，中国硬核资产长牛未央**——香江策论深度报告
> （31 字含副题，正题 20 字，**0 个数字**）

拆句法：`国际秩序重构`（主语）`危中有机`（谓语）｜`中国硬核资产`（主语）`长牛未央`（谓语）。
**两个完整主谓判断，有主体、有方向。**

### 4.2 两个模型的标题各自错在哪

| 版本 | 标题 | 句法实况 |
|---|---|---|
| GLM | 零安全垫下的拉锯：盈利未失速，约束未松 | 冒号前**是名词**（"拉锯"是状态标签，无谓语）；冒号后两项是局部否定。读者拿不到方向，也拿不到动作含义 |
| DeepSeek | 零安全垫横盘，方向未决 | 前句无主语；后句"方向未决"是**元判断**——在陈述"我自己判断不出来"，把犹豫当结论卖 |

**共病**：都在"压成短句"这一步退化成标签，而不是判断。
两者都不是"谁 → 会怎样 → 所以该怎么办"，这正是老板说的
"连最基本的语法和主体都没有"。

### 4.3 标题能不能写动作？—— 能，但要带主体和方向

老板此前问过"动手是什么？加仓还是减仓？"，由此断言"动作不能放标题位"。
**修正**：动作**可以**进标题，前提是点名仓别与方向。

- 病句：`站上 734.58 或跌破 702.70 再动手` ← "动手"没有对象和方向
- 合格：`核心仓不加码，等待者不动` ← 主体（核心仓/等待者）+ 方向（不加码/不动）都在

⇒ 纪律应该是"**标题若提动作，必须点名仓别与方向**"，而不是"标题不许提动作"。

## 5. 回答老板的三个不确定

### 5.1 四要素要不要都包含？—— 要，但它们已有归宿，不必挤进一段

| 要素 | 已有字段 |
|---|---|
| 状态 | `state_diagnosis` |
| 价格 | `priced_narrative` + `price_reflection_map` |
| 赔率 | `payoff_assessment` |
| 动作 | `portfolio_actions`（+ `reader_final.action_summary`） |

判决正文里也已自然覆盖：段 1（姿态 + 赔率 + 时间尺度）、段 5（价格与执行）、
段 6（赔率与等待代价）。

⇒ **"四要素必须出现"这个义务应该落在"字段齐不齐 / 正文提没提到"，
而不是落在某一段必须怎么写。** 把四要素当成某一段的写作配方，才是它们变成
同一个模子的原因（两家模型分句数都是 9，就是被这个配方挤出来的）。

### 5.2 要不要锁顺序？—— 只锁一条，其余不锁

**锁**：正文**第一段必须把完整判断先说完**（判断先行）。
依据：四份范本首段全部这么做（张忆东首段"国际秩序重构，全球经济或将走向
动荡与滞胀风险"）。这是倒金字塔，不是八股。

**不锁**：`状态 → 价格 → 赔率 → 动作` 这个顺序。把它定成唯一顺序，就是老板说的
"像写八股文一样"。范本段落顺序是按**分量**排的，不是按要素排的。

### 5.3 字数上限？—— 范本没有字数纪律，只有段落纪律

实测范本：

| 范本 | 事实 |
|---|---|
| Marks《Sea Change》 | 段落 406–812 字，**无字数纪律** |
| 张忆东封面摘要 | **7 段**，每段 41–428 字；段首全是独立成句的硬结论 |
| 我方判决正文 | 6 段，165–506 字 ← **已经合规** |
| 我方改后导语 | **1 段 606 字** ← 病在"1 段"，不在"606 字" |

⇒ **不要用字数当闸门。** 600 字本身不是罪，600 字挤在一段才是罪。
若要有机器闸门，用**段落**（必须空行分段、每段一个意思），不用字数——
这与 `contracts.py:2340`（T69 P0-1）已判过的"**字数代理'有料'是形状代理语义**"
同一个道理。

## 6. 方案 D（我推荐，等于把老板的判断落成结构）

**首屏撤掉导语，门面 = 标题 + 判决正文。**

```
kicker（元信息）
h1             ← headline（标题：一句判断）
badges         ← 姿态 / 赔率 / 可信度
reasoned-verdict ← 判决正文（六段，已有）
jumplinks
```

一次性解决三件事：
1. **标题位**——归 `headline`，不再被摘要占着；
2. **职位重合**——第二层撤掉，不再有同义复述；
3. **600 字一段**——那 606 字就长在导语里，随它一起下线。

**施工面（比方案 A 小）**

| 项 | 动作 |
|---|---|
| `vnext_reporter.py:2566-2578` | 删掉 `lead_html`（`facade-lead`）分支 |
| `slate_v3.css` / `slate_v2.css` | `.facade-lead` 样式可留（无害）或删 |
| `run_review.py:967` | "导语非空"检查改为"**判决正文非空**"（导语不再是首屏必填） |
| 提示词 `final_adjudicator.md` | Step 2 只写 `headline`；`one_liner` 不再要求写读者导语（字段保留，下游用） |
| 提示词【门面体例】节 | 加**范本标题样例**（张忆东那句）+ 两条病句反例（本轮两个标题），沿用 T72"整段范本"方法，**不新增卡规则** |
| 10 处 `one_liner` 下游 fallback | **全部不动**——字段还在，台账/回看不破 |

**与方案 B 的区别**：B 是废字段 + 重接线 5 处消费点；D 是**只撤渲染**，
字段与下游全部保留，风险面小一个数量级。

**备选 D2**：导语保留但**限成标题下的一句话**（≤60 字，只给结论）。
好处是有个"一句话"入口；坏处是又把字段切回两半，且与判决正文段 1 继续重合。
**我不推荐**——判决正文段 1 已经是那句话了。
