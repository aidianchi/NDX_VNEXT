### 闸门宪法（第一性原理，先立尺子再过堂）

**闸门的全部合法职权只有四类机械事实**（代码能确定性判定、判错可复现）：

1. **身份**——这东西是谁的：schema_version、judgment_object、编号归属、代码装配字段；
2. **形状**——机器能不能解析、装配、审计：JSON 可解析、枚举合法、必填结构在；
3. **存在性**——引用的东西真在账上吗：evidence ref 在白名单、event_id 在底账、hypothesis_id 在本轮清单；
4. **时点**——时点纪律：effective_date、回测不偷看未来。

**禁区**：一切要"读懂内容"才能判的东西——道理对不对、措辞谦不谦逊、有没有断言方向、长短有没有料。**用形状代理语义同样越权**：字数代理"有没有料"、关键词代理"态度"，都是本次 W1-A/W1-D 实锤的病。

**内容质量的把关不走闸门**，走三条别的路：提示词原则（教育，不拦截）＋ 事后审计抽查（T63/T64 线）＋ 将来的评分闭环（T09）。运行时拦截整份产出是原则上不批的最后手段。

### 总纲前置：老板六原则（08-28 深夜口述，AI 提炼，**草稿待老板点头后生效**）

1. **架构一致律**：代码与文档描述的架构必须一致；架构错了，一切局部修补无效。
2. **注意力优先律**：每次 AI 调用（五层/桥梁/终审/批评者……）都按"充分必要的上下文，优雅投喂"组装，让注意力最好；输出只干本职——深度分析。
3. **不埋没人才律**：不许让分析师干脏活——背字段名、复读固定句子、填编号、凑字数、管标点括号；少个括号多俩字就打回重跑，是把人才当打字员。
4. **仆从律**：代码为 Agent 服务——递材料、做簿记、做排版；把 Agent 当主人。材料组装对了，很多闸门自然失业。
5. **报刊律**：HTML/报告是报刊排版——文章让专家写，代码只排版；专家不写 HTML、不干装配。
6. **第一性判定律**：限制的存废只问一句——"不这样，深度分析还能被信任地交付吗？"能答"能"的限制，默认可删。

### 闸门宪法 v2（08-28 深夜修订：执法姿势 + 参照物）

原宪法四类（身份/形状/存在性/时点）保留分类，但**执法姿势全面改造**——老板指出："如果我们本身输入的东西就不会偷看未来，它怎么偷看未来？它吃到的上下文都是我们给的。"成立。因此：

- **时点/存在性重新定性：它们审的是我们的组装，不是模型**。闸门响了=我们漏喂材料/漏过滤=管道 bug——响铃给开发者修管道，**绝不打回模型重跑、绝不整份作废**（TradingAgents 同理：look-ahead 过滤做在数据输入层，不做在输出闸门）。
- **存在性的误伤通道要堵死**：模型引用了真实存在但白名单没发的材料=我们的错。根治两件：白名单从实际发出的 payload 导出（T42① 已做，推广到全站）＋"请求补材料"走既有补采通道而不是剥引用了事。
- **传输宽容最大化**：解析层把"格式噪音"全吸掉（键名别名映射、类型强转、多余字段剥离、固定句子代码追加）——参照 TradingAgents `_coerce_optional_float`：模型写 "N/A" 进数字字段，它强转成 None 让校验通过，而不是报错重跑。
- **兜底永远是自由文本**：结构化失败≠拦截，降级为散文照收（TradingAgents `invoke_structured_or_freetext`："so the pipeline never blocks"）。我们的对应物=既有降级路径，保留但只能更宽容。

**参照物结论（TradingAgents，08-28 核查）**：该框架基本无输出闸门——主产物是散文（其源码自述），结构化只给三个决策岗做薄层；格式错误→宽容强转或降级自由文本，永不阻塞；look-ahead 过滤做在输入数据层。它不要求可审计，我们要（北极星：事实扎实可追溯），所以我们比它多留"存在性"一类，且仅以装配自检姿势执法。**它证明：无语义闸门照样能跑，不是理想主义。**
