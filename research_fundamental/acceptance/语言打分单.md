# 语言打分单（验证期每期用）

## 这是什么

新器官（重建后的主编排器）有连续五期的验证期，每期产出的报告由你验收。这张单子是你读报告时的打勾清单：机器层加四档阅读分开打分，任何一档不过，那一档退回重做，不许拿别档的好成绩代偿。每期打完勾，把结果记进文末的表；连续五期全部合格，新器官的产出才值得信任。

判定依据是 `research_fundamental/Q8_whitelist/ideal_blueprint.md` 第 5.1 节（卡一：三层楼语言卡）。

## 第〇档：机器层（不用你读，只抄结果）

每次运行后，代码会自动拿报告全文逐字比对生造词黑名单（系统已确认的生造词清单，比如"零垫"）。黑名单零命中才算过；命中一个，本期直接不合格。你在阅读中新发现的生造词，记进记档表的缺陷栏，交维护者登记进清单，下次运行起机器自动拦截。

## 第一档：塔尖一分钟

翻到报告第一屏的结论段，掐一分钟，逐条打勾：

- [ ] **逐句找主语。** 每句话都找得到"谁怎么样"。发现只剩词组、找不到主语的句子，本档不过。
- [ ] **有方向性断言。** 报告明确说了方向（比如看涨、看跌、减仓、不行动）。出现"可能涨也可能跌"这类两边都不得罪的免责套话，本档不过。
- [ ] **不确定都带行动含义。** 每一处"不确定"后面，紧跟它对行动的含义（比如"这一点不确定，所以仓位只减一半"）。只说不确定、不说怎么办的，本档不过。
- [ ] **风险全是条件句。** 每条风险都写成"什么情形发生 → 什么结论受影响"的句子（比如"若信用利差两周内回落到年内低点以下，本次转弱判断撤销"）。只写"存在回调风险"这类没情形、没影响的裸句，本档不过。

## 第二档：塔身十分钟

读理由一节，约十分钟：

- [ ] **理由都是完整句。** 每一步理由是一句完整的话，有主语、有谓语，不是词组堆砌。
- [ ] **争议判断两侧都有论据。** 凡有争议的判断，支持侧和反对侧各至少有一份代表性论据（能代表该侧最强理由的那一份）摆出来。只摆一侧的，本档不过。
- [ ] **未裁决分歧明写。** 作者没有裁决的分歧，报告里明写"这里存在分歧"。为了让报告读起来顺而把分歧抹平的，本档不过。

## 第三档：塔基三十分钟

读证据与推理链一节，约三十分钟，做三个抽查：

- [ ] **抽一条推理链读到底。** 随机挑一条从证据到结论的推理链，从头读到尾，不许断。四种断法都不算过：缺中间环节（从甲直接跳到丙，没说乙）、指代不明（"它""这个"不知道指谁）、循环论证（拿结论证明结论）、收口断裂（前面的推理和最后的结论对不上）。
- [ ] **抽十个数字逐个要来源。** 随机挑十个数字，每个都要得出出生证：哪个机构发布、出自哪个数据序列、哪天发布。指不回来源的数字，它所在段落的结论自动降级，不能当正式结论用。
- [ ] **口径冲突必须裁决。** 两处数字口径（统计口径，比如含不含股息、是官方公布数还是估算数）不一致时，报告必须写明采用哪个、为什么。把两种口径并列放过、不裁决的，本档不过。

## 第四档：人复述

- [ ] 把报告交给一个不了解前因的人（家人、朋友皆可）。他能复述出三件事才算过：报告说的是谁、事情会怎么样、我该干什么。复述不出来的，本档不过。

## 合格判定

一期合格 = 机器层零命中 + 四档全过。任何一档不过，整档退回，不许用别档代偿。注意：验证期的"信任"还要求完成一次性的上下文菜单核对（蓝图第 5.2 节的卡二），那张卡不在这张单子上。
